Core Objective

Learning objective: Recognise fractions that represent the same amount.

Understanding Equivalent Fractions

Equivalent fractions name the same amount using different numbers. When two fractions are equivalent, they describe the exact same portion of a whole, even though the whole has been divided into a different number of equal parts.
