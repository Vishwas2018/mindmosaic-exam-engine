# MindMosaic Landing Page — Independent UI/UX, Product and Architecture Audit

## Executive Verdict

The landing page is credible, cohesive and close to launch quality, but it is not yet at the standard of a polished $1M SaaS platform.

| Area | Current Rating |
|---|---:|
| Visual design | 8.2/10 |
| Brand consistency | 8.5/10 |
| Product clarity | 7.5/10 |
| Conversion readiness | 7.2/10 |
| Trust and credibility | 6.8/10 |
| Kid-friendliness | 7.4/10 |
| Accessibility readiness | 6.5/10 |
| Technical and product maturity communicated | 6.8/10 |
| Overall | **7.5/10** |

The foundation is strong. The remaining gap is not simply visual polish. The page needs to feel more authoritative, trustworthy, accessible and commercially complete.

# Highest-Priority Issues

## 1. Text Is Still Too Small

This is the most visible issue.

Many elements appear too small for comfortable everyday use:

- Navigation
- Card descriptions
- Trust-bar text
- Feature descriptions
- Process descriptions
- Pricing bullets
- Disclaimer text
- FAQ answers
- Footer links

This affects readability, accessibility, older parents, low-vision users and mobile users.

### Recommended Minimum Sizes

| Element | Minimum |
|---|---:|
| Body copy | 16px |
| Card description | 14–15px |
| Navigation | 14–15px |
| Button text | 15–16px |
| Supporting metadata | 14px |
| Legal text | 12–13px with strong contrast |
| FAQ question | 16px |
| FAQ answer | 15–16px |

Avoid very light grey text as a way to reduce visual density.

## 2. Header Lacks Premium Presence

The header is neat but visually too light.

### Current Issues

- Logo is undersized
- Navigation links are small
- Login is visually weak
- The CTA is isolated
- Sticky behaviour is not evident

### Recommended Changes

- Header height: 72–76px
- Increase logo size by 10–15%
- Use 14–15px medium-weight navigation
- Make the header sticky
- Add a light border
- Add subtle background blur
- Add strong hover and focus states
- Use a proper mobile navigation drawer

## 3. Trust Claims Need Evidence

The page currently makes claims such as:

- Trusted by Australian learners
- Parent-friendly progress insights
- Curriculum aligned
- Original questions

These are useful messages, but they need support.

### Better Evidence

- 388 original questions available
- Content reviewed against Australian curriculum skills
- Every question checked for correctness, clarity and originality
- Progress reports designed for parents
- No official assessment questions copied or reconstructed

Add a methodology link:

> See how our questions are created and reviewed

Avoid broad claims such as “trusted by Australian learners” until genuine usage evidence exists.

## 4. Content Quality Is Underexplained

Assessment quality is a critical buying criterion.

The page should explain:

- Who creates questions
- How correctness is checked
- How ambiguity is reviewed
- How visuals are validated
- How age suitability is confirmed
- How originality is protected
- How users can report an issue

### Recommended New Section

## Quality You Can Trust

Include:

- Original questions only
- Independently reviewed answers
- Age-appropriate language
- Australian English
- Visual consistency checks
- Curriculum and skill mapping
- Question-reporting process

## 5. Kid-Friendliness Is Mostly Photographic

The site shows children, but the product experience itself is not strongly shown as child-friendly.

A kid-friendly platform should visibly demonstrate:

- Clear question layouts
- Friendly feedback
- Encouraging language
- Simple navigation
- Low-pressure practice mode
- Readable typography
- Progress celebrations
- Accessibility controls
- Age-appropriate visuals

### Recommendation

Add a product-preview section showing:

- Exam interface
- Practice feedback panel
- Progress page
- Student dashboard

Use real product screenshots rather than only lifestyle photography.

# Accessibility Audit

The screenshot alone does not demonstrate that the page is fully accessible.

## Likely Concerns

### Typography

Several text elements appear below practical minimum sizes.

### Contrast

Pale grey and purple text on white or lavender backgrounds requires formal contrast validation.

### Keyboard Access

Confirm:

- Visible focus rings
- Correct tab order
- Keyboard-operated FAQ accordions
- Accessible mobile navigation
- No keyboard traps

### Semantic Structure

Confirm:

- One H1 only
- Logical H2/H3 hierarchy
- Proper landmarks
- Correct button and link semantics
- FAQ ARIA state
- Accessible navigation labels

### Images

- Meaningful images need descriptive alt text
- Decorative floating cards should use empty alt text
- No alt text should reveal assessment answers

### Motion

Respect `prefers-reduced-motion`.

### Target Sizes

All interactive controls should be at least 44 × 44px.

### Forms

Newsletter form should include:

- Visible label
- Validation message
- Privacy context
- Accessible success announcement

## Recommended Accessibility Target

- WCAG 2.2 AA
- Zero serious or critical axe violations
- Full keyboard completion of all public journeys
- 200% zoom without content loss
- 320px responsive support
- Screen-reader validation for navigation, forms and FAQ

# Solution Architecture Concerns

The landing page promises functionality that must be supported by production-ready services and controls.

Validate that the following are real:

- Progress tracking
- Parent dashboard
- Curriculum alignment
- Original content governance
- Multi-child family support
- Secure child data handling
- Instant explanations
- Assessment-specific pathways
- Question accuracy controls
- Accessibility
- Subscription entitlement enforcement
- Responsive behaviour
- Session recovery
- Autosave

The landing page should not promise features before their routes, APIs, security controls and data models are production-ready.

## Technical Readiness Checks

- All CTAs resolve correctly
- Images use WebP or AVIF
- Responsive `srcset` is present
- Hero image is prioritised
- Below-the-fold images are lazy-loaded
- Images reserve layout space
- Fonts are preloaded correctly
- Image sizes match rendered dimensions
- Metadata is configured
- Open Graph image is present
- Canonical URL is configured
- Analytics and consent behaviour are compliant
- Forms have rate limiting
- Newsletter form has anti-spam protection
- Error monitoring is configured
- No secrets are exposed client-side

# Final Position

MindMosaic is no longer at an early prototype stage. The landing page looks like a real product and has a strong brand foundation.

However, it still presents as a well-designed emerging SaaS platform rather than an established premium platform.

The main gaps are:

- Readability
- Supporting evidence
- Product authenticity
- Accessibility proof
- Launch-scope clarity
- Real interface previews
- Deeper trust architecture

Correcting these issues should move the landing page from approximately **7.5/10 to around 9/10** without requiring a full redesign.
