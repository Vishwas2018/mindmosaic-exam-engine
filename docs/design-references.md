# Design references (external, read-only)

Source: https://github.com/VoltAgent/awesome-design-md

Reference only. Never copy a company's DESIGN.md verbatim into this project —
MindMosaic keeps its own identity (see `docs/design.md`, the canonical,
mandatory design contract).

Relevant premium SaaS examples in that repo, each as a `DESIGN.md` +
`preview.html`/`preview-dark.html` set:

- **Stripe** — payment infra, weight-300 elegance
- **Linear** — ultra-minimal, precise, purple accent (closest tonal match to MindMosaic's `#5925A8` primary)
- **Vercel** — black/white precision, Geist font
- **Airtable** — colourful, friendly, structured-data aesthetic
- **Apple** — premium white space, SF Pro, cinematic imagery

## MindMosaic identity (do not drift from this)

- Primary: `#5925A8`
- Accent: `#FF555A`
- Background: `#FCFBF8`
- Style: premium, calm, modern educational SaaS
- Avoid: childish styling, excessive gradients, decorative clutter, generic AI-generated layouts

Use Linear and Vercel as the closest reference points for restraint and
precision; use Stripe for typographic elegance; avoid Airtable's playful
colour density and Apple's imagery-heavy hero patterns — neither fits an
educational SaaS aimed at calm, trustworthy tone.
